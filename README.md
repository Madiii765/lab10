# Финансовый учёт

Консольное приложение на Python для учёта доходов и расходов.

## Возможности

- добавление доходов и расходов;
- просмотр истории операций;
- расчёт общего баланса;
- формирование отчёта за выбранный период;
- удаление ошибочно добавленной операции;
- статистика доходов и расходов по категориям;
- сохранение и загрузка данных в CSV;
- проверка вводимых данных и обработка ошибок.

## Требования

- Python 3.9 или новее;
- дополнительные библиотеки устанавливать не нужно.

## Запуск программы

Откройте терминал в папке проекта и выполните:

```bash
python main.py
```

В Windows также можно использовать:

```bash
py main.py
```

## Главное меню

| Пункт | Действие |
|---|---|
| 1 | Добавить доход |
| 2 | Добавить расход |
| 3 | Показать историю операций |
| 4 | Показать баланс |
| 5 | Отчёт за период |
| 6 | Удалить операцию |
| 7 | Статистика по категориям |
| 0 | Сохранить данные и выйти |

При вводе даты используйте формат `ДД.ММ.ГГГГ`. Если дата операции не указана, программа использует текущую дату. Сумму можно вводить с точкой или запятой в качестве десятичного разделителя.

## Хранение данных

Операции сохраняются в `transactions.csv`, который располагается рядом с `main.py`. При следующем запуске программа автоматически загружает сохранённые операции. Этот файл содержит пользовательские данные и исключён из Git через `.gitignore`.

## Запуск тестов

```bash
python -m unittest -v
```

Тесты проверяют добавление и удаление операций, проверку входных данных, расчёт баланса, сортировку и фильтрацию по датам, отчёты, статистику категорий, а также сохранение и загрузку CSV.
